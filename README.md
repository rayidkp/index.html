# Live Stream

A minimal HTML-based HLS video player page.

## Features

- Full-screen video playback
- HLS streaming support through hls.js
- Native HLS fallback for compatible browsers
- Simple, distraction-free interface

## Project Structure

- `Premier league.html` — HLS video player page

## Usage

Open the HTML page through a compatible web server and provide a valid HLS stream URL.

## Technology

- HTML5 Video
- JavaScript
- hls.js

## Note

Only use HLS streams that you are authorized to access and distribute. Avoid committing private or temporary signed stream URLs to public repositories.
